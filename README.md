# Odin Recipes

A simple multi-page recipe website built as part of [The Odin Project](https://theodinproject.com) Foundations curriculum.

## Tech Stack
* HTML5
* CSS3

## Features
* Organized recipe directory (Lasagna, Tacos)
* Custom CSS styling and layout adjustments

## What I Learned
* Structuring multi-page HTML configurations
* Committing and pushing code using Git and WSL2
